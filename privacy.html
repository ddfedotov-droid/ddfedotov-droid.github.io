Privacy policy

DF agents · Last updated October 24, 2026

DF agents is a personal tool. Its only user is its owner, and it accesses only the owner's own Google account.

Data it accesses

With the owner's consent, DF agents uses the Gmail API with the read-only scope gmail.readonly. It reads only messages from bank senders the owner has explicitly listed. From each alert it keeps the date, amount, merchant name, and a message identifier.

How the data is used and stored

  • The data is used only to build the owner's personal spending ledger.
  • The ledger and the access token are stored only on the owner's computer, and not on any server operated for this app.
  • DF agents never sends, modifies, labels, or deletes email.

Sharing

Data is never sold, used for advertising, or shared with anyone. There is one optional exception that the owner controls. If the owner turns on merchant suggestions and clicks a button, the text of that single merchant name is sent to Anthropic's Claude API so it can explain what the merchant is. No email content, amounts, dates, or account details are sent.

Limited use

The use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Removing access

The owner can revoke access at any time at myaccount.google.com/permissions and delete the local ledger and token from their computer.
